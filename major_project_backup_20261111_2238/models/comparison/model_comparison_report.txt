used for training, checkpoint selection, or tuning.

Model size and inference time
-----------------------------
EfficientNetB0: 17,065,889 bytes (17.07 MB); 4,054,695 parameters.
MobileNetV2: 21,785,346 bytes (21.79 MB); 2,263,108 parameters.
Batch-1 inference latency: EfficientNetB0 57.949 ms/image; MobileNetV2
33.521 ms/image. These existing measurements used the same 32 balanced
validation images (8 per class), with warm-up excluded and image decoding and
resizing excluded. They are reported measurements, not new estimates.
Peak memory and FLOPs were not measured. MobileNetV2 training time is
unavailable in its existing evaluation report.

Selection
---------
The recorded test metrics support EfficientNetB0 as the final classification
model: it has higher accuracy, macro precision, macro recall, macro F1-score,
and Gray_Leaf_Spot recall, while its serialized model is smaller. It is slower
on the recorded batch-1 benchmark, and its Gray_Leaf_Spot precision (0.8421)
is slightly below MobileNetV2 (0.8444); this class-specific false-positive
trade-off should remain visible in deployment review. No formal acceptance
thresholds were supplied, and the reported test set must not be used to tune
the model or confidence threshold.
