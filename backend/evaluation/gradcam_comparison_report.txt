Method details
--------------
Grad-CAM uses the spatial average of first-order class-score gradients as channel weights.
Grad-CAM++ uses gradient-power alpha weights (squared gradients in the numerator and squared/cubed-gradient terms in the denominator), then combines positive gradients with feature-map activations.
Both methods target the model's predicted class and use the same normalized 7x7 activation maps, OpenCV JET color scale, original image, and 0.45 overlay opacity.

Limitations
-----------
Both methods are approximate class-activation explanations. Heatmaps do not prove a prediction is correct, identify a disease cause, or establish causal feature importance.
The final feature map is only 7x7 before resizing, so displayed regions have limited spatial detail.
Grad-CAM++'s gradient-power weighting is a local attribution heuristic; map detail or concentration alone is not evidence of better explanations.
This comparison reuses the same model and the exact image filenames from the existing Grad-CAM report; it does not retrain or alter the test split.
