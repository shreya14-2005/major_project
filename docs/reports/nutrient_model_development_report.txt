1. EXECUTIVE SUMMARY
--------------------------------------------------------------------------------
A dedicated, independent deep-learning classification pipeline has been designed,
implemented, trained, evaluated, and verified for diagnosing maize leaf nutrient
deficiencies across five conditions:
  - Healthy (All essential nutrients balanced)
  - Magnesium (Mg) Deficiency
  - Nitrogen (N) Deficiency
  - Phosphorus (P) Deficiency
  - Potassium (K) Deficiency

Key Accomplishments:
  * Strict Isolation: Zero modifications, overwrites, or retraining occurred on the
    existing maize disease classification module (EfficientNetB0, 96.18% accuracy,
    SHA-256: 4EEBD71DF1C7E076A0B477F3BE3B1DD3927F101B37ABFC9CC7B60EFD2660C733).
  * Dataset Integrity: All 463 original field images are preserved untouched in
    'datasets/Maize Nutrient Deficiency Dataset/'.
  * Leakage-Proof Splitting: Five perceptual near-duplicate candidate pairs were
    identified, clustered, and kept strictly within identical split partitions,
    guaranteeing zero data leakage between train, validation, and test subsets.
  * Transfer Learning: Pretrained MobileNetV2 and EfficientNetB0 models were trained
    under identical, reproducible split conditions with balanced class weighting.
  * Model Selection: Model selection was performed strictly using validation performance.
    EfficientNetB0 was selected based on superior validation loss (0.3609 vs 0.3868)
    and higher macro recall (85.31% vs 83.90%), maintaining architectural harmony
    with the primary disease classifier.
  * Unbiased Final Evaluation: The selected model was evaluated on the untouched test
    set (71 images) exactly ONCE after model selection, achieving 92.96% accuracy,
    0.9337 macro precision, 0.9316 macro recall, and 0.9300 macro F1-score.
  * Standalone Inference: A modular, standalone CLI predictor was developed and
    verified across all five classes with input validation and medical/biological
    diagnostic disclaimers.

4. MODEL TRAINING CONFIGURATION & METHODOLOGY (PHASE 3)
--------------------------------------------------------------------------------
Hardware & Software Environment:
  * Python: 3.12.0
  * TensorFlow: 2.18.1
  * Keras: 3.15.1
  * Compute Device: Intel/AMD CPU (No discrete GPU detected; local training executed cleanly)

Architectures Evaluated:
  1. MobileNetV2 (ImageNet pretrained backbone, alpha=1.0)
     - Input Shape: 224 x 224 x 3
     - Preprocessing Layer: Keras native Rescaling(scale=1/127.5, offset=-1.0) mapping to [-1, 1].
     - Head: GlobalAveragePooling2D -> Dropout(0.30) -> Dense(5, softmax).
  2. EfficientNetB0 (ImageNet pretrained backbone)
     - Input Shape: 224 x 224 x 3
     - Preprocessing Layer: Keras native Rescaling(scale=1.0, offset=0.0) keeping [0, 255]
       for internal normalization.
     - Head: GlobalAveragePooling2D -> Dropout(0.30) -> Dense(5, softmax).

Training Protocol:
  * Batch Size: 16
  * Class Imbalance Mitigation: Scikit-learn balanced class weighting:
      - Class 0 (Healthy):    1.2920
      - Class 1 (Magnesium):  0.7512
      - Class 2 (Nitrogen):   0.9362
      - Class 3 (Phosphorus): 0.8177
      - Class 4 (Potassium):  1.6564
  * Training Augmentation (Applied ONLY to Train Generator):
      - Random Horizontal Flip
      - Random Rotation (+/- 0.05 / ~18 deg)
      - Random Zoom (+/- 0.10)
  * Two-Stage Transfer Learning:
      - Stage 1 (Head Warmup): Backbone frozen, Adam lr = 1e-3, 15 epochs max.
        Callbacks: EarlyStopping (patience=5), ReduceLROnPlateau (factor=0.2, patience=2).
      - Stage 2 (Fine-Tuning): Unfreeze top 30 layers, BatchNormalization kept in inference
        mode, Adam lr = 1e-5, 15 epochs max.
        Callbacks: EarlyStopping (patience=5), ReduceLROnPlateau (factor=0.2, patience=2),
        ModelCheckpoint (save_best_only=True based on val_loss).

Model Selection Decision & Justification:
  * Selected Architecture: EfficientNetB0
  * Primary Reasons:
    1. Superior Generalization: EfficientNetB0 achieved lower cross-entropy validation loss
       (0.3609 vs 0.3868), indicating higher probability calibration and confidence reliability.
    2. Higher Macro Recall: EfficientNetB0 captured 85.31% macro recall across all classes
       (compared to 83.90% for MobileNetV2), vital for reducing false negatives in nutrient stress.
    3. Architectural Consistency: PlantHealthAI's primary disease classifier is EfficientNetB0;
       standardizing on EfficientNetB0 across both modules streamlines inference pipelines.
  * Preserved Research Comparison: MobileNetV2 weights are saved in:
    'models/nutrient_detection/mobilenetv2_nutrient_best.keras'.
